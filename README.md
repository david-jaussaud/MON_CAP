# MON CAP

MON CAP est un projet de planner premium pensé pour une impression A5, avec une identité visuelle nature, zen et inspirée du dragon asiatique.

## Objectif

Construire un planner de 200 à 300 pages à partir de gabarits HTML/CSS réutilisables, puis générer un PDF A5 propre pour l'impression.

## Direction graphique initiale

- Nature et végétal
- Déclinaisons de vert : sauge, jade, mousse, forêt
- Fond ivoire
- Esthétique zen, sobre et contemporaine
- Dragon asiatique comme signature visuelle, utilisé avec parcimonie

## Architecture

- `index.html` : prototype web principal
- `src/css/` : styles écran et impression
- `src/templates/` : futurs gabarits du planner
- `src/data/` : futures données structurées
- `assets/` : illustrations, motifs et icônes
- `docs/` : décisions éditoriales et graphiques

## Règle de travail

GitHub est la source officielle du projet. Le HTML/CSS est la source maîtresse de mise en page. L'export PDF sera dérivé de cette source.
